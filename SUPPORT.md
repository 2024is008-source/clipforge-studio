# Support & Help

## Getting Help with ClipForge
1. **Documentation**: Check [`docs/installation/SETUP_GUIDE.md`](docs/installation/SETUP_GUIDE.md) and [`docs/troubleshooting/TROUBLESHOOTING.md`](docs/troubleshooting/TROUBLESHOOTING.md).
2. **System Pre-Flight Check**: Run `run.bat --check` on Windows to verify Node.js, Python, FFmpeg, and worker packages.
3. **Bug Reports**: Open a new issue using the [Bug Report template](.github/ISSUE_TEMPLATE/bug_report.md).
